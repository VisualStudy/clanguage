# Hello World 반복 출력 프로그램

## 📌 프로그램 설명

이 프로그램은 `for` 반복문을 사용하여 `"hello World"` 문자열을 5번 출력하는 간단한 C 언어 예제입니다.

---

## 📄 코드

```c
#include <stdio.h>

int main(void)
{
    for (int x = 0; x < 5; x++)
    {
        printf("hello World\n");
    }

    return 0;
}
